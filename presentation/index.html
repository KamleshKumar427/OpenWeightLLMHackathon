Asumistuen hakeminen

          

            

              
Asumistuki on Kelan maksama etuus, jonka tarkoituksena on helpottaa pienituloisten kotitalouksien asumismenoja. Etuuden saaminen edellyttää, että hakija täyttää tulo- ja varallisuusedellytykset sekä asuu vakituisesti tuettavassa asunnossa, jonka vuokra ei ylitä kunnan määrittelemiä enimmäisasumismenoja.

              
Hakemus tulee jättää viimeistään sen kuukauden loppuun mennessä, jolta tukea haetaan. Mikäli hakemus jätetään myöhässä, etuutta ei makseta takautuvasti, vaikka kaikki edellytykset täyttyisivätkin jo aiemmin.

    How it works
    
    
    An extension, an open model, a safe patch.
    
    
    
      
    
        
      
    
      
    
        
    01 · READSnapshot the page, measure it
    
        
    02 · PLANThe model decides what to change
    
        
    03 · APPLYSafe, undoable edits
    
        
    04 · CHECKRe-measure, fix what’s left
    
        
    05 · REWRITEPlain-language text, in parallel
    
      
    
    
    
    
    The model never writes code. It returns a small JSON patch.Chrome extension · plain JavaScript · no backend of ours

    European compute.
